# UI Polish

Third post-v1 update. Bundles four small, visually-scoped backlog items from [`roadmap.md`](../roadmap.md) into one branch, since they share the same review surface (CSS + a visual walkthrough of every page) rather than any backend logic. Purely frontend, no backend/infra touched — same shape as [Account Details](2026-08-05-account-details.md) in that respect.

## Requirements & decisions

- Scope: four items from `../roadmap.md`'s backlog, plus three found along the way:
  1. Loading-screen placement/style
     - The same `LoadingMessage` component (`Loader2` + "Loading...") gets centered within its container via CSS (`.status-message.status-loading`), rather than rebuilt as an overlay or per-page skeleton — smallest change that fixes the awkward top-left placement.
  2. General layout density/whitespace pass
     - Exploratory, no fixed plan going in — this update tracks what gets found/changed per page as the walkthrough happens, rather than a pre-enumerated checklist.
  3. Mobile/responsive pass
     - Same as above — exploratory, walkthrough-driven.
  4. Entry table cell overflow/truncation
     - Already fully specified by the backlog note itself — in `LogTypeEntries.tsx`'s table, cap column width, add `text-overflow: ellipsis` truncation, with the full value available via `title` attribute on hover.
  5. Browser tab title
     - [`frontend/index.html`](../../frontend/index.html)'s `<title>` is still the default Vite template value ("frontend"), never changed to "Logger's World" — found while working on this branch, not from the original backlog.
  6. Delayed loading indicator
     - A `useDelayedLoading(loading, delay?)` hook that only surfaces `true` after a short threshold (e.g. 200ms) of sustained loading, so fast requests never flash the spinner at all — found while reviewing item 1's centering fix. Replaces raw `loading` state reads in each page that renders `LoadingMessage`.
  7. Full-page offline state
     - `fetch()` throws a plain `TypeError` (e.g. "Failed to fetch") when there's no network connectivity, before a response even exists — today that's indistinguishable from a real API error once it reaches each page's generic `catch (err) { setError(err.message) }`, so a network outage shows the same small inline error message as any other failure, and only a full page refresh (triggering the browser's own native offline page) makes it obvious what's actually wrong. `api.ts`'s `apiFetch` will throw a distinguishable `NetworkError` instead, each data-loading page will render a dedicated full-page "You're offline" view (via a new `OfflineMessage` component) when it catches one, and a `useOnlineRetry` hook will listen for the browser's `online` event to automatically retry once connectivity returns — found while testing the loading-spinner fix with DevTools' network throttling.
     - Covers all five pages, including `Profile.tsx`. Its data load doesn't use `apiFetch` — it calls Cognito directly through `AuthContext`'s `getUserAttributes()` — but that SDK has its own network-failure error, which `AuthContext` now converts into the same `NetworkError`, so `Profile.tsx` handles it the same way as the other four pages.
  8. Post-walkthrough polish batch
     - A background agent scanned the frontend for remaining polish opportunities once the density/mobile passes were done; found items were triaged and applied in one batch:
       - Checkbox `color-scheme` mismatch: `:root` set `color-scheme: light dark` globally, so native form-control chrome (e.g. the "Required" checkbox) followed the OS's dark-mode preference instead of the app's own `data-theme` toggle — now pinned per `data-theme` value.
       - Entries table's Edit/Delete actions made consistent: Edit changed from a bare link to a pill button matching Delete, both icon-only at every viewport (previously icon+text).
       - `LogTypeBuilder`'s "Remove field" button given a `Trash2` icon, matching the destructive-action convention used elsewhere.
       - ~180 lines of dead `npm create vite` scaffold CSS removed from `App.css` (`.counter`, `.hero`, `#center`, `#next-steps`, `#docs`, `#spacer`, `.ticks`) — confirmed unreferenced by any component first.
       - `RowMenu`'s `.row-actions` wrapper given actual layout rules (`display: inline-flex; align-items: center`) instead of being a no-op class.
       - Icon sizes standardized into named constants (`ICON_SM`/`ICON_MD`/`ICON_LG` in a new `iconSizes.ts`), replacing ~26 scattered numeric `size={..}` literals across every page/component.
       - `.danger-zone h2` no longer overrides the global `h2` font-size (still keeps the `--error` color).
